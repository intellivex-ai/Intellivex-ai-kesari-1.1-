## 2025-01-20 - Memoizing MessageRow
**Learning:** Found that `MessageRow` in `src/App.tsx` was not memoized, causing unnecessary re-renders of the entire message list whenever the chat state (like typing indicator, new stream chunks) updated. This is a common performance bottleneck in React chat applications.
**Action:** Applied `React.memo` (imported as `memo` from `react`) to `MessageRow` to prevent re-rendering of all historical messages when only the latest message or input state changes.
## 2026-06-04 - Zustand Selector Optimization\n**Learning:** Found that multiple components (App, WorkspacePanel, CodeBlock) were destructuring from `useWorkspaceStore()` without using selectors or `useShallow`. This Zustand anti-pattern causes components to re-render whenever *any* state in the store changes, rather than only when the consumed state changes. This is a significant performance bottleneck in React applications.\n**Action:** Replaced direct destructuring with `useShallow` from `zustand/react/shallow` to bundle state subscriptions efficiently and prevent unnecessary component re-renders.
